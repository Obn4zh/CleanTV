# TV Cleaner (портативная версия)

Очищает Android TV и Google TV от рекламы, телеметрии и лишних приложений и ставит чистый лаунчер.
Программа работает на любом ПК с Windows 10 или 11 без установки: Python, adb и всё остальное уже
лежат в этой папке.

## Запуск

1. Распакуйте архив в любую папку, например на флешку.
2. Дважды щёлкните **`TV Cleaner.bat`**.
3. Если окно не появилось, запустите `TV Cleaner (console).bat`: он покажет ошибку.

Windows может спросить, доверять ли файлу из интернета. Ответьте «Подробнее → Выполнить в любом случае».

## Перед подключением, на телевизоре

Откройте «Настройки → Об устройстве» и 7 раз нажмите «Сборка». Затем в разделе «Для разработчиков»
включите **«Отладку по USB»** и **«Отладку по сети»**. Если у ТВ есть только **«Отладка по Wi-Fi»**,
включите её. Компьютер и ТВ должны быть в одной сети.

У программы свой ключ отладки. Поэтому при первом подключении с неё ТВ спросит «Разрешить отладку?»,
даже если раньше вы подключались с этого ПК другим способом. Для «Отладки по Wi-Fi» один раз
выполните сопряжение по коду на вкладке «Подключение».

## Где хранятся данные

Всё хранится в папке **`data`** рядом с программой: записи для отката, бэкапы, списки по каждому
устройству и ключ adb. Программа ничего не пишет в профиль Windows. Поэтому на другом ПК откат
работает так же, если папка переносится целиком.

- **Не удаляйте `data`**, пока может понадобиться откат.
- **Не передавайте другим папку `data`**: в ней ваш ключ adb, а ТВ, которые ему доверяют, дадут
  с ним доступ. Чтобы поделиться программой, отдайте исходный архив или копию без `data`.

## Что внутри

- `app`: сама программа.
- `cleanyourtv`: скрипты, списки по моделям и собранный лаунчер из проекта
  [cleanyourtv](https://github.com/Gathin23/cleanyourtv), лицензия MIT в `cleanyourtv\LICENSE`.
  В `cleanyourtv\tools\venv\Scripts` лежит собственный Python программы.
- `platform-tools`: adb от Google.

Лаунчер в архиве уже собран, его домашний экран настраивается программой через тему. Чтобы
пересобрать лаунчер из исходников, нужен полный репозиторий cleanyourtv с JDK и Android SDK.

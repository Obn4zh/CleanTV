# CleanTV (TV Cleaner)

Оконная программа для Windows: убирает с Android TV и Google TV рекламу, телеметрию и
предустановленный мусор и ставит чистый лаунчер. Всё делается по сети, без root, пакеты
отключаются, а не удаляются, и откат делается в один клик.

Это графическая оболочка над скриптами проекта
[cleanyourtv](https://github.com/Gathin23/cleanyourtv). С устройством работают именно они, поэтому
их защиты остаются в силе:
- ядро Android и `com.android.tv.settings` никогда не отключаются;
- стоковый лаунчер отключается только после того, как новый стал главным экраном;
- на Google TV проверяется, какому приложению принадлежит сохранённый Wi-Fi;
- перед любыми изменениями сохраняются бэкап и запись для отката.

## Что умеет

1. **Подключение.** Находит ТВ в сети через mDNS. Работает и с «Отладкой по сети» (порт 5555),
   и с «Отладкой по Wi-Fi»: для неё есть сопряжение по коду.
2. **Что отключить.** Если в cleanyourtv есть проверенный список для этой модели, программа берёт его.
   Если нет, предлагает пакеты по похожим устройствам и статистике по всем спискам, а отмечает
   заранее только безопасное. Стриминги, ассистент, Chromecast и обновления помечены «ваш выбор».
   Пользовательские приложения и ядро системы в список не попадают.
3. **Лаунчер.** Ставит лаунчер, настраивает док (4–8 приложений), заставку-часы, запрет
   автообновлений и кнопку-шестерёнку для пультов Google TV.
4. **Запуск.** Выполняет очистку, затем перезагружает ТВ и проверяет, что всё сохранилось.
5. **Откат.** Возвращает пакеты, стоковый лаунчер, заставку, службы специальных возможностей
   и настройку обновлений. По желанию удаляет лаунчер.

## Портативная версия

Готовый архив `TVCleaner-portable.zip` лежит в разделе
[Releases](https://github.com/Obn4zh/CleanTV/releases). Внутри Python, adb, списки и уже
собранный лаунчер. Распакуйте его и запустите `TV Cleaner.bat`. Все данные хранятся в папке
`data` рядом с программой.

## Запуск из исходников

Положите рядом три папки:

```
<любая папка>\
  CleanTV\          этот репозиторий
  cleanyourtv\      git clone https://github.com/Gathin23/cleanyourtv
  platform-tools\   adb от Google (Android SDK Platform-Tools)
```

В `cleanyourtv` подготовьте окружение и соберите лаунчер, как описано в его README. Нужны JDK 17
и Android SDK 34.

```powershell
cd cleanyourtv
python -m venv tools\venv
tools\venv\Scripts\python.exe -m pip install -r tools\requirements.txt
```

После этого запустите `TV Cleaner.bat` или выполните `python tvcleaner.py`.

Другие пути можно задать в `settings.json` рядом с программой:

```json
{"repo": "D:\\cleanyourtv", "adb": "D:\\platform-tools\\adb.exe", "android_home": "C:\\AndroidSDK"}
```

### Сборка портативного архива

```powershell
py -3.14 make_portable.py
```

Скрипт собирает папку `dist\TVCleaner` и архив `dist\TVCleaner-portable.zip`. В архив входят
копия установленного Python с tkinter, библиотеки adb-shell, adb и нужная часть cleanyourtv.

## Где хранятся данные

| Версия | Записи для отката, бэкапы, профили |
|---|---|
| Из исходников | `%USERPROFILE%\.tvcleaner\` и `%USERPROFILE%\.cleanyourtv\` |
| Портативная | папка `data` рядом с программой |

Пока может понадобиться откат, эти папки не удаляйте. В портативной папке `data` лежит ваш ключ
adb, поэтому другим её не передавайте.

## Ограничения

- Кнопки пульта, которые перехватывает сама прошивка (например, Netflix на стиках Xiaomi),
  переназначить нельзя.
- «Отладка по Wi-Fi» после перезагрузки выключается и получает новый порт. Это поведение Android:
  её нужно включить снова и переподключиться.
- Для модели без проверенного списка предложение стоит просмотреть самому.
- Кнопку-шестерёнку обрабатывает служба специальных возможностей лаунчера. Другое приложение
  со своей службой, например пульт с телефона или Button Mapper, может при включении выключить
  её. Поэтому вместе с опцией «шестерёнка» включается автовосстановление: открыв главный экран,
  лаунчер вернёт службу сам. Для этого он получает разрешение `WRITE_SECURE_SETTINGS`. Если
  выключить службу вручную в «Настройки → Спец. возможности», она останется выключенной.
